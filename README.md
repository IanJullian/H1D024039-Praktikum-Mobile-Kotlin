# Aplikasi Jualan - Praktikum Mobile

Aplikasi **Jualan** adalah platform sederhana yang dirancang untuk mewadahi produk lokal UMKM di Kabupaten Purbalingga, Jawa Tengah. Aplikasi ini dibangun menggunakan **Jetpack Compose** untuk antarmuka pengguna yang modern dan deklaratif.

## Fitur Utama

- **Informasi Dasar (Basic Info)**: Menampilkan logo, deskripsi singkat aplikasi, dan misi utama UMKM.
- **Hubungi Kami (Form)**: Formulir sederhana bagi pengguna untuk mengirimkan pesan atau pertanyaan melalui email.
- **Navigasi**: Menggunakan Jetpack Navigation untuk berpindah antar halaman dengan lancar.

## Teknologi yang Digunakan

- **Kotlin**: Bahasa pemrograman utama.
- **Jetpack Compose**: Toolkit modern untuk membangun UI native Android.
- **Jetpack Navigation**: Untuk manajemen navigasi antar layar.
- **Material Design 3 (M3)**: Standar desain UI terbaru dari Google.

## Struktur Proyek

- `MainActivity.kt`: Entry point aplikasi dan konfigurasi `NavHost`.
- `ui/screen/BasicInfoScreen.kt`: Halaman awal yang berisi informasi tentang aplikasi.
- `ui/screen/HubungiKamiScreen.kt`: Halaman formulir kontak.
- `ui/theme/`: Konfigurasi tema aplikasi (Warna, Tipografi, Tema).

## Cara Menjalankan

1. Clone repositori ini.
2. Buka proyek di **Android Studio Ladybug** atau versi terbaru.
3. Sinkronkan Gradle (Gradle Sync).
4. Jalankan aplikasi pada Emulator atau Perangkat Fisik (API 29+).
